## 1. 학습방식 종류

| 종류   | 학습 목표 | 예시  |
| ---- | ----- | --- |
| 지도학습 |정답(라벨)을 맞추도록 학습|분류, 회귀|
| 비지도학습 | 정답 없이 구조를 찾음 | 군집화, 차원 축소, 이상 탐지|
| 강화학습 | 행동에 대한 보상을 최대화하도록 학습 | 로봇 제어, 게임 |
| 준지도 학습 | 라벨이 있는 데이터 소량 + 라벨이 없는 데이터 다량을 함께 학습 | 라벨이 없는 데이터가 더 많음 |
| 자기지도학습 | 데이터 스스로 문제를 만들어 사전학습 | 다음 단어 맞추기 |


## 2. 데이터 분할

| 데이터 세트 | 역할 | 규칙  |
| ---- | ----- | --- |
| 학습(train) |모델 가중치를 학습|-|
| 검증(validation) | 하이퍼파라미터·모델 선택 | 여러 번 수행 가능|
| 테스트(test) | 최종 성능 보고 | 1회만 사용 |

- 교차 검증(k-fold): 데이터를 k등분해 돌아가며 검증 -> 데이터가 적을 때 성능 추정이 안정적임.
- 층화(stratified): 각 조각에 클래스 비율을 똑같이 유지함. 불균형 데이터에서는 필수적임.
- 그룹 분할: 같은 그룹이 학습과 테스트에 나뉘어 들어가지 않게 함.

## 3. 과적합과 과소적합

|이름|증상|대책|
|---|---|---|
|과적합(overfitting)|학습 성능 높음, 검증 성능 낮음. 학습 데이터를 외움.|데이터 늘리기, 데이터 증강, 정규화(L1/L2), 드롭아웃, 조기 종료(early stopping), 모델 단순화|
|과소적합(underfitting)|학습 성능부터 낮음. 패턴을 못 배움|모델 키우기, 특성 추가, 학습 더 하기|

- 편향-분산 트레이드 오프: 단순한 모델은 편항(bias)가 큼 -> 과소적합, 복잡한 모델은 분산(variance)이 큼 -> 과적합. 그 사이 균형점을 찾아야 함.
- L1은 가중치를 0으로 만들어 특성을 선택하는 효과가 있고, L2는 가중치를 작게 유지함.

## 4. 데이터 누수 (data leakage)

- 정의: 학습할 때 실제 사용 시점에는 알 수 없는 정보가 섞여 들어가는 것

| 유형 | 예시 |
| --- | --- |
| 전처리 누수 | 스케일링·정규화를 전체 데이터로 fit한 뒤 분할 -> 테스트 통계가 학습에 스며듦|
|중복·그룹 누수| 같은 출처의 데이터가 학습과 테스트에 동시에 존재 |
|시간 누수| 미래 데이터로 과거를 예측|
|타겟 누수| 정답에서 파생된 특성이 입력에 포함됨|

- 보통 데이터 누수가 발생했을 때, 비현실적으로 성능이 좋게 나옴

## 5. 분류 평가지표

### 참고: 혼동행렬

||예측positive|예측negative|
|---|---|---|
|실제positive|TP|FN|
|실제negative|FP|TN|

### 분류 평가지표

|지표|계산|의미|
|---|---|---|
|Accuracy|(TP+TN)/total|전체 중 정답 비율|
|Precision|TP / (TP+FP)|positive라고 한 것 중에 정답 비율|
|Recall(= 민감도, Sensitivity)|TP/(TP+FN)|실제 positive 인 것 중에 정답 비율|
|F1|2·P·R/(P+R)|P(Precision)와 R(Recall)의 조화평균, 0~1의 값이며 1에 가까울수록 좋음|
|Specificity|TN/(TN+FP)|실제 negative 인 것 중에 정답 비율|

#### 평가지표 활용
- Positive를 놓치면 안됨 -> Recall 우선
- 오탐 비용이 큼 -> Precision 우선
- 둘 다 중요 -> F1
- Recall과 Precision은 기본적으로 trade off 관계

#### 곡선 지표

|지표|내용|대상|
|---|---|---|
|ROC-AUC|임계값을 바꿔가며 TPR(Recall) vs FPR(=FP/(FP+TN))을 그린 곡선의 아래 면적|클래스가 비교적 균형일 때|
|PR-AUC|Precision vs Recall 곡선의 면적|Positive가 드물 때 더 정직함|

#### 다중 클래스 평균 방식

|방식|계산|특징|
|---|---|---|
|Macro|클래스별 지표를 구해 단순 평균|소수 클래스도 똑같이 반영, 불균형에서 추천|
|Weighted|클래스 크기로 가중 평균|다수 클래스에 끌려감|
|Micro|전체 TP·FP·FN을 합산해 계산|단일 라벨 다중 분류에서는 accuracy와 같음|

## 7. 불균형 데이터 대응

|방법|내용|
|---|---|
|리샘플링|다수/소수 클래스에 따라, 언더샘플링 혹은 오버샘플링 수행. SMOTE(소수 클래스 합성)|
|클래스 가중치|손실 함수에서 소수 클래스의 오답에 더 큰 벌점|
|데이터 증강|소수 클래스 이미지 회전·반전 등 수정|
|임계값 조정|소수 클래스를 더 쉽게 positive 판정|
|지표 선택|accuracy 대신 macro-F1, 클래스별 Recall, PR-AUC|
