# 딥러닝 기초

## 딥러닝

### 1. 신경망의 기본 단위

- 뉴런: 입력에 가중치를 곱해 더하고, 편향(bias)을 더한 뒤 활성화 함수를 통과시킴.
- output = f(w₁x₁ + w₂x₂ + … + b)
- 활성화 함수가 없으면 층을 아무리 쌓아도 선형 변환 하나와 같음. 비선형성을 가진 활성화 함수를 통해 복잡한 패턴을 학습할 수 있음

|활성화 함수|출력 범위|주 용도|
|---|---|---|
|ReLU|0 이상 (max(0, x))|은닉층 기본값. 계산이 싸고 기울기 소실이 적음|
|Sigmoid|0~1|이진 분류 출력층 (확률)|
|Softmax|0~1, 합이 1|다중 분류 출력층|
|Tanh|-1~1|0을 중심으로 하므로 시그모이드보다 최적화 과정이 안정적, RNN 내부 등|

### 2. 학습이 일어나는 과정

1. 순전파(forward): 입력 -> 예측값
2. 손실(loss) 계산: 예측이 정답과 얼마나 다른지를 계산

예시)
   - 분류 -> 교차 엔트로피(cross-entropy)
   - 회귀 -> MSE
3. 역전파(backpropagation): 연쇄 법칙(chain rule)으로 각 가중치의 기울기(gradient) 계산
4. 옵티마이저가 가중치 갱신: SGD, Adam(가장 흔한 기본값)

cf) 가중치 학습 과정 용어

|용어|의미|
|---|---|
|학습률(learning rate)|한 번에 고치는 크기. 너무 크면 발산·진동, 너무 작으면 학습이 느림|
|배치(batch)|가중치를 한 번 갱신할 때 쓰는 샘플 묶음|
|이터레이션(iteration)|배치 하나로 한 번 갱신|
|에폭(epoch)|학습 데이터 전체를 한 번 다 보는 단위|

### 3. 깊은 신경망의 문제와 해결

|문제|내용|해결|
|---|---|---|
|기울기 소실(vanishing gradient)|층이 깊으면 앞쪽 층으로 갈수록 기울기가 0에 가까워져 학습이 안 됨|ReLU, 잔차 연결(residual connection, ResNet), 배치 정규화|
|기울기 폭주|기울기가 너무 커짐|기울기 클리핑|
|과적합|학습 성능 높음, 검증 성능 낮음. 학습 데이터를 외움|드롭아웃, 정규화, 데이터 증강, 조기 종료|

- 배치 정규화(batch normalization): 층의 입력 분포를 정규화해 학습을 안정시키고 빠르게 함.
- 드롭아웃: 학습할 때 뉴런 일부를 무작위로 끔. 추론시에는 다시 전체 enable후 사용.

### 4. CNN (합성곱 신경망)

|구성|역할|
|---|---|
|합성곱(convolution) 층|작은 필터(커널)를 이미지 위로 밀며 국소 패턴(모서리, 점, 선)을 찾음 → 결과는 특징 맵(feature map)|
|가중치 공유|같은 필터를 이미지 전체에 재사용 → 파라미터 수가 크게 줄어듦|
|스트라이드(stride)|필터가 한 번에 이동하는 칸 수|
|패딩(padding)|가장자리에 0을 둘러 출력 크기 유지|
|풀링(pooling)|영역의 최댓값(max)·평균만 남겨 크기를 줄임 → 계산량 감소, 작은 위치 변화에 둔감해짐|
|완전연결(FC) 층 + softmax|마지막에 클래스 확률 출력|

- 전형적 구조: [합성곱 → ReLU → 풀링] × N개 → FC → softmax
- 출력 크기 공식: (입력 크기 - 커널 크기 + 2 x 패딩) / 스트라이드 + 1

예) 입력 64, 커널 3, 패딩 1, 스트라이드 1 → (64 − 3 + 2) / 1 + 1 = 64

- 국소 패턴을 잡고 가중치를 공유하는 특성으로 인해 이미지 처리에 효과적이라는 특징이 있음.

### 5. RNN과 Transformer

||RNN / LSTM|Transformer|
|---|---|---|
|처리 방식|토큰을 하나씩 순서대로 처리, 은닉 상태로 기억 전달|모든 토큰을 한 번에 처리 (병렬화 가능)|
|약점|긴 문장에서 앞 내용을 잊음 (LSTM이 게이트로 일부 완화)|계산량이 문장 길이의 제곱에 비례|
|핵심|순환 구조|셀프 어텐션(self-attention)|

#### 셀프 어텐션 (self-attention)
- 각 토큰이 문장 안의 다른 모든 토큰을 보고, 어디에 얼마나 주목할지 가중치를 계산함.
- 구성: 각 토큰을 Query(Q), Key(K), Value(V)로 바꾸고 → softmax(QKᵀ / √d) · V
- 멀티헤드 어텐션: 여러 관점(문법, 의미 등)의 어텐션을 동시에 계산함.
- 위치 인코딩: 한 번에 처리하므로 순서 정보가 없어서, 위치 정보를 따로 더해 줌.


|구조|대표 모델|강점|
|---|---|---|
|인코더만|BERT|문장 이해 (분류, 검색)|
|디코더만|GPT, Claude 등 대부분의 LLM|문장 생성|
|인코더-디코더|T5, 원래 Transformer|번역, 요약|


### 6. 전이학습과 데이터 증강
- 전이학습(transfer learning): 큰 데이터로 미리 학습한 모델을 가져와 마지막 층만 바꿔 활용하는 방식
  - 특징 추출: 앞 층은 고정(freeze)하고 마지막 층만 학습 -> 데이터가 적을 때
  - 미세 조정(fine-tuning): 전체 또는 일부 층을 낮은 학습률로 추가 학습 -> 데이터가 충분할 때
- 데이터 증강: 회전, 반전, 자르기, 노이즈 등으로 학습 데이터를 늘림.
  - 학습 세트에만 적용함.
  - 라벨이 바뀌지 않는 변형만 사용함.
